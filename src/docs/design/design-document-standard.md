# Lighthouse Design Document Standard

## Purpose

This document defines the standard structure for all Lighthouse design documents.

The goal is consistency, readability, and maintainability across the project.

---

## Writing Guidelines

• Keep documents focused on one feature.

• Describe behavior before implementation.

• Explain the "why," not only the "what."

• Prefer examples over abstract descriptions.

• Update version history when major design changes occur.
